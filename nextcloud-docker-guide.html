ÉTAPE 01
Vérifier les prérequis
▼
Avant de commencer, mettons à jour Ubuntu et vérifions que tout est en ordre.

Mettre à jour le système

bash
sudo apt update && sudo apt upgrade -y

Trouver votre IP locale (VMware)

bash
ip addr show
# Cherchez l'interface ens33 ou eth0 — notez l'adresse 192.168.x.x
📡
VOTRE IP VMware (exemple)
192.168.1.XXX
⚠️ Dans VMware, vérifiez que la carte réseau est en mode Bridged (Pont) et non NAT, pour que les autres machines du réseau puissent accéder à Nextcloud.
  • Système mis à jour (apt update/upgrade)
  • IP locale notée quelque part
  • VMware en mode Bridged (réseau ponté)
🐳
ÉTAPE 02
Installer Docker & Docker Compose
▼
On installe Docker Engine officiel (pas la version snap) et le plugin Compose.

Installer les dépendances

bash
sudo apt install -y ca-certificates curl gnupg lsb-release

Ajouter le dépôt officiel Docker

bash
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg \
  | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
  https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" \
  | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

Installer Docker

bash
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin

Ajouter votre utilisateur au groupe docker

bash
sudo usermod -aG docker $USER
newgrp docker
# Ou redémarrez votre session

Vérifier l'installation

bash
docker --version
docker compose version
✅ Résultat attendu : Docker version 26.x.x et Docker Compose version v2.x.x
📄
ÉTAPE 03
Créer le fichier docker-compose.yml
▼
On crée un dossier dédié et le fichier de configuration qui définit Nextcloud + sa base de données.

Créer le dossier du projet

bash
mkdir -p ~/nextcloud && cd ~/nextcloud

Créer le fichier docker-compose.yml

bash
nano docker-compose.yml
📄 docker-compose.yml 
version: '3.8'

services:

  db:
    image: mariadb:10.11
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: rootpassword123
      MYSQL_DATABASE: nextcloud
      MYSQL_USER: nextcloud
      MYSQL_PASSWORD: nextcloudpass456
    volumes:
      - db_data:/var/lib/mysql

  nextcloud:
    image: nextcloud:latest
    restart: always
    ports:
      - "8080:80"
    depends_on:
      - db
    environment:
      MYSQL_HOST: db
      MYSQL_DATABASE: nextcloud
      MYSQL_USER: nextcloud
      MYSQL_PASSWORD: nextcloudpass456
      NEXTCLOUD_TRUSTED_DOMAINS: 192.168.1.XXX
    volumes:
      - nextcloud_data:/var/www/html

volumes:
  db_data:
  nextcloud_data:
⚠️ Remplacez 192.168.1.XXX par l'IP réelle de votre VM Ubuntu. Changez aussi les mots de passe par des valeurs sécurisées.
🚀
ÉTAPE 04
Lancer Nextcloud
▼
On démarre tous les conteneurs en arrière-plan et on vérifie que tout tourne bien.

Démarrer les conteneurs

bash
cd ~/nextcloud
docker compose up -d
# Le téléchargement des images prend 2-5 minutes

Vérifier que les conteneurs tournent

bash
docker compose ps
# Les deux services doivent être "Up"

Voir les logs en direct (optionnel)

bash
docker compose logs -f nextcloud
# Ctrl+C pour quitter
ℹ️ Attendez ~1 minute après le démarrage avant d'accéder à l'interface web. Nextcloud initialise sa base de données au premier lancement.
⚙️
ÉTAPE 05
Configurer Nextcloud (1er accès)
▼
Ouvrez un navigateur sur votre machine hôte (Windows/Mac) et accédez à Nextcloud.
🌐
ACCÉDER À NEXTCLOUD DEPUIS LE RÉSEAU LOCAL
http://192.168.1.XXX:8080

Formulaire de création du compte admin

  • Choisir un nom d'utilisateur admin (ex: admin)
  • Choisir un mot de passe fort
  • Dans "Base de données" → sélectionner MySQL/MariaDB
  • Utilisateur DB : nextcloud
  • Mot de passe DB : celui de votre docker-compose.yml
  • Nom de la DB : nextcloud
  • Hôte de la DB : db
🎉 Cliquez sur "Installer" et patientez 1-2 minutes. Nextcloud va installer les apps de base automatiquement.
🔗
ÉTAPE 06
Accès réseau local & conseils
▼
Partagez Nextcloud avec les autres appareils de votre réseau local.

Depuis n'importe quel appareil du réseau

📱
URL D'ACCÈS (PC, téléphone, tablette...)
http://192.168.1.XXX:8080

Commandes utiles

bash — Gestion quotidienne
# Arrêter Nextcloud
docker compose down

# Redémarrer
docker compose restart

# Mettre à jour Nextcloud
docker compose pull && docker compose up -d

# Voir l'utilisation des ressources
docker stats

Démarrage automatique au boot

bash
# Docker démarre automatiquement (déjà activé par défaut)
sudo systemctl enable docker
# Les conteneurs avec "restart: always" démarrent aussi automatiquement
💡 Pour une IP fixe sur votre VM, configurez une adresse IP statique dans Ubuntu ou réservez l'IP dans votre box/routeur via l'adresse MAC.
🔒 Pour un usage uniquement sur réseau local, HTTP suffit. Si vous exposez un jour à internet, ajoutez HTTPS avec Let's Encrypt et un reverse proxy (ex: Nginx Proxy Manager).
