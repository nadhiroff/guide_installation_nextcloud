Préparation
Mettre à jour le système & noter l'IP
▼
On commence par une mise à jour complète du système et on identifie l'adresse IP de la VM.

Mise à jour Ubuntu

bashterminal
sudo apt update && sudo apt upgrade -y

Trouver votre IP locale

bash
ip addr show
# Notez l'adresse 192.168.x.x (interface ens33 ou eth0)
📡
ADRESSE IP DE VOTRE VM
192.168.1.XXX
⚠️ Dans VMware, carte réseau en mode Bridged (Ponté) obligatoire pour que les autres appareils du réseau puissent accéder à Nextcloud.
02
Installation
Installer Apache, MariaDB & PHP
▼
On installe toute la pile LAMP en une seule commande, puis les extensions PHP nécessaires à Nextcloud.

Installer Apache + MariaDB + PHP 8.3

bashinstallation complète
sudo apt install -y \
  apache2 \
  mariadb-server \
  php8.3 libapache2-mod-php8.3 \
  php8.3-gd php8.3-mysql php8.3-curl php8.3-mbstring \
  php8.3-intl php8.3-gmp php8.3-bcmath php8.3-xml \
  php8.3-imagick php8.3-zip php8.3-bz2 \
  php8.3-ldap php8.3-apcu php8.3-redis \
  unzip wget curl

Activer les modules Apache nécessaires

bash
sudo a2enmod rewrite headers env dir mime
sudo systemctl restart apache2

Vérifier qu'Apache tourne

bash
sudo systemctl status apache2
# Doit afficher : active (running)
03
Base de données
Configurer MariaDB
▼
On sécurise MariaDB et on crée la base de données dédiée à Nextcloud.

Sécuriser l'installation MariaDB

bash
sudo mysql_secure_installation
# Répondez :
# Switch to unix_socket auth → N
# Change root password → Y  (choisissez un mot de passe)
# Remove anonymous users → Y
# Disallow root login remotely → Y
# Remove test database → Y
# Reload privilege tables → Y

Créer la base de données Nextcloud

bash
sudo mysql -u root -p
SQLdans le prompt MariaDB
CREATE DATABASE nextcloud CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
CREATE USER 'nextcloud'@'localhost' IDENTIFIED BY 'VotreMotDePasse123!';
GRANT ALL PRIVILEGES ON nextcloud.* TO 'nextcloud'@'localhost';
FLUSH PRIVILEGES;
EXIT;
🔑 Notez bien le mot de passe choisi pour l'utilisateur nextcloud — vous en aurez besoin à l'étape 5.
04
Configuration
Configurer PHP pour Nextcloud
▼
On ajuste les limites PHP pour que Nextcloud fonctionne correctement (upload, mémoire, temps d'exécution).

Éditer php.ini

bash
sudo nano /etc/php/8.3/apache2/php.ini
💡 Dans nano, utilisez Ctrl+W pour rechercher. Trouvez et modifiez ces valeurs :
php.ini /etc/php/8.3/apache2/php.ini 
# Recherchez et modifiez ces lignes :
memory_limit = 512M
upload_max_filesize = 10G
post_max_size = 10G
max_execution_time = 360
max_input_time = 360
date.timezone = Europe/Paris
output_buffering = Off

Redémarrer Apache

bash
sudo systemctl restart apache2
05
Téléchargement
Télécharger & installer Nextcloud
▼
On télécharge la dernière version de Nextcloud et on la place dans le répertoire web d'Apache.

Télécharger Nextcloud

bash
cd /tmp
wget https://download.nextcloud.com/server/releases/latest.tar.bz2
wget https://download.nextcloud.com/server/releases/latest.tar.bz2.sha256
sha256sum -c latest.tar.bz2.sha256 < latest.tar.bz2
# Doit afficher : OK

Extraire et déplacer vers Apache

bash
tar -xjf latest.tar.bz2
sudo mv nextcloud /var/www/html/nextcloud

Donner les bonnes permissions

bashimportant
sudo chown -R www-data:www-data /var/www/html/nextcloud
sudo chmod -R 755 /var/www/html/nextcloud

Créer le dossier de données (hors webroot)

bashbonne pratique sécurité
sudo mkdir -p /var/nextcloud-data
sudo chown -R www-data:www-data /var/nextcloud-data
06
Apache
Configurer le Virtual Host Apache
▼
On crée un fichier de configuration Apache dédié à Nextcloud.

Créer le Virtual Host

bash
sudo nano /etc/apache2/sites-available/nextcloud.conf
nextcloud.conf /etc/apache2/sites-available/nextcloud.conf 
<VirtualHost *:80>
    ServerName  192.168.1.XXX
    DocumentRoot /var/www/html/nextcloud

    <Directory /var/www/html/nextcloud/>
        Require all granted
        AllowOverride All
        Options FollowSymLinks MultiViews

        <IfModule mod_dav.c>
            Dav off
        </IfModule>
    </Directory>

    ErrorLog  ${APACHE_LOG_DIR}/nextcloud_error.log
    CustomLog ${APACHE_LOG_DIR}/nextcloud_access.log combined
</VirtualHost>
⚠️ Remplacez 192.168.1.XXX par l'IP réelle de votre VM Ubuntu.

Activer le site et désactiver le site par défaut

bash
sudo a2ensite nextcloud.conf
sudo a2dissite 000-default.conf
sudo apache2ctl configtest
# Doit afficher : Syntax OK
sudo systemctl reload apache2
07
Finalisation
Premier accès & configuration web
▼
Ouvrez un navigateur sur n'importe quel appareil du réseau et finalisez la configuration de Nextcloud.
🌐
ACCÉDER À NEXTCLOUD
http://192.168.1.XXX

Remplir le formulaire d'installation

  • Nom d'utilisateur admin → votre choix (ex: admin)
  • Mot de passe admin → fort et unique
  • Dossier de données → /var/nextcloud-data
  • Type de base de données → MySQL/MariaDB
  • Utilisateur DB → nextcloud
  • Mot de passe DB → celui créé à l'étape 3
  • Nom de la DB → nextcloud
  • Hôte de la DB → localhost
🎉 Cliquez sur "Installer". L'installation prend 2-3 minutes. Nextcloud est ensuite accessible depuis tous les appareils du réseau local !
